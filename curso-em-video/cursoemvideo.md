# Curso em Vídeo — POO em Python

Exercícios do curso de Programação Orientada a Objetos em Python, do 
[Curso em Vídeo](https://www.cursoemvideo.com/).

## Padrão de cada desafio

Cada pasta `desafioXXX/` contém:
- `__main__.py` — ponto de entrada / testes
- `classe.py` — implementação da(s) classe(s) pedida(s)
- `desafioXXX.md` — enunciado do desafio (com diagrama de classes, quando aplicável)

Para a lista completa com descrição de cada exercício, veja o 
[índice no README principal](../README.md#cursoemvideo).

**OBS:** os exercícios não foram feitos usando a biblioteca *rich* igual foi usado nos vídeos.
